# 上班盯盘助手 - 官网发布包（Gitee Pages 专用）

本文件夹内所有内容就是官网的全部文件，**整个文件夹原样上传到 Gitee 仓库根目录即可**，无需修改任何路径。

## 目录说明

```
官网发布/
├── index.html                  ← 官网首页（Gitee Pages 自动识别）
├── 发布版/上班盯盘助手.exe       ← 官网"下载"按钮的文件（9.2MB）
├── 股票摸鱼工具素材/            ← 头像、官网大图、软件图标等
├── 账号二维码/                  ← 抖音 / bilibili / 小红书二维码
└── 收款码/                      ← 微信 / 支付宝收款码
```

## Gitee Pages 部署步骤

1. **实名认证**：登录 Gitee → 右上角头像 → 设置 → 实名认证（Gitee Pages 服务强制要求）。
2. **新建仓库**：仓库名建议 `shangban-dingpan`（或随意英文名），可见性选"公开"，不要勾选自动初始化文件。
3. **上传文件**：进入仓库 → 「上传文件」→ 把本文件夹内**所有文件与子文件夹**拖进去 → 提交。
   - 注意：务必让 `index.html` 位于仓库**根目录**（不要多套一层文件夹）。
   - 网页端单文件限制 20MB，本包最大文件 9.2MB，可以直接网页上传；如提示超限，用 git 命令行推送。
4. **启动 Pages**：仓库页 → 「服务」→ 「Gitee Pages」→ 点「启动」：
   - 部署分支：选择你上传代码的分支（默认 master）
   - 部署目录：留空（根目录）
   - 强制 HTTPS：可选
5. **等待部署**：首次约 1~5 分钟，完成后得到网址：
   `https://<你的用户名>.gitee.io/<仓库名>`
6. **更新内容**：以后改了官网，重新上传覆盖文件后，回到 Gitee Pages 点「更新」即可（免费版需手动更新）。

## 常见问题

- **404 / 打不开**：确认仓库根目录有 index.html；确认 Pages 服务已启动且部署分支正确。
- **提示需实名认证**：完成实名后重新启动 Pages。
- **图片不显示**：检查上传后中文文件夹名是否完整（保持本包目录名不变）。
- **下载按钮失效**：确认 `发布版/上班盯盘助手.exe` 已随仓库上传。
- **自定义域名**：Gitee Pages 免费版支持绑定自有域名，在 Pages 设置里填写并在域名服务商加 CNAME 即可。

## 修改官网的方法

直接编辑本文件夹里的 `index.html`（同时建议同步修改 `../上班盯盘助手官网.html` 主副本），改完重新上传 + 点「更新」。
